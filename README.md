# CanvasApp

An iOS application built with Swift for drawing and canvas manipulation.

## Technologies Used

- **Platform**: iOS
- **Language**: Swift
- **IDE**: Xcode

## Project Structure

- Native iOS application with Xcode project files
- Includes UI tests and unit tests
- Asset catalog for app resources

## Setup

1. Open the project in Xcode:
```bash
open CanvasApp/CanvasApp.xcodeproj
```

2. Select your target device or simulator

3. Build and run the project (Cmd + R)

## Requirements

- macOS with Xcode installed
- iOS deployment target as specified in project settings
